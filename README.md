# Space Escape - Text-Based Adventure Game

A sci-fi themed text adventure game where you wake up in a cryo chamber aboard a damaged spaceship and must find your way to the escape pod.

## Features
- 7 explorable rooms with atmospheric descriptions
- Inventory system for collecting and using items
- Puzzle-solving mechanics (locked doors, keycard system)
- Enemy encounter with multiple solutions
- 2 different endings based on player choices

## How to Play
1. Run the game: `python Final_Project.py`
2. Use commands like: `look`, `go [direction]`, `take [item]`, `use [item]`
3. Type `help` for full command list

## Technologies
- Python 3
- Data structures (nested dictionaries)
- Conditional logic and state management
